# EcoMiles — Contest Packets

This directory consolidates official registration documents, project proposals, financial workbooks, and submission materials for the startup competitions EcoMiles is participating in.

| Competition | Host Institution / Organizer | Track | Directory | Key Deliverables |
|---|---|---|---|---|
| **Olympic Khởi nghiệp 2026 (SO 2026)** | Đại học Kinh tế Quốc dân (NEU) & Trung tâm Đổi mới sáng tạo và Hướng nghiệp (CICN) | Kinh doanh tạo tác động xã hội | [`SO_2026/`](SO_2026/) | Contest Paper, Registration & Commitment Form, Pitch Deck |
| **RnD to Startup 2026** | Đại học Quốc gia Hà Nội (VNU) & Vườn ươm khởi nghiệp ĐMST ĐHQGHN | Môi trường & phát triển bền vững | [`RND_2026/`](RND_2026/) | Project Description (Docx & MD), Financial Models (XLSX), Team Commitment |
