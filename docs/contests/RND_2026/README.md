- **Track**: Môi trường & phát triển bền vững (Environment & Sustainable Development).
- **Project Name**: **GREENLOGIX** (Nền tảng tối ưu tuyến đường vận tải đô thị và đo lường phát thải CO₂).
- **Live MVP Demo**: [https://greenlogix.w9.nu/](https://greenlogix.w9.nu/)
