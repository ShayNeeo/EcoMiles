# Change Request: `CR-20260913-001`

> Integrator (human or AI): read **§1 then §3** before looking at the diff.

## 1. Outcome

**Objective** (one sentence): Replace solver tour km with a `RoadBaseline` interface backed by free OSM (Valhalla auto/truck or OSRM driving) plus circuity fallback, and add an optional eco-weighted routing cost hook, so a Google Directions key can plug in later without scraping.

**Why now:** SO 2026 contest novelty must be shipped in code before 2026-09-25. No Google Maps key exists. Baseline vs optimized remains Excel-order vs NN+2-opt (not Google).

**Base:** `origin/so2026` @ `26857792eaf44866434bded476f018ead8176d7a`
