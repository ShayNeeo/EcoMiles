## 4. Frozen Contracts

### 4.1 `emission_factors.json` Additive WTW Keys
Keep existing `petrol` (`kg_co2_per_litre: 2.31`) and `diesel` (`kg_co2_per_litre: 2.68`) intact; add `"wtw_kg_co2_per_litre": 2.82` on `petrol` and `"wtw_kg_co2_per_litre": 3.24` on `diesel` (GLEC Framework v3.2 / ISO 14083:2023 WTW defaults, matching `energy/hdt_v1.py:27-31`).

### 4.2 `/analytics/kpis` & `/report` Additive PVM / ASI Decomposition
Inside `carbon` block of `GET /analytics/kpis` (and `ReportMetrics` of `GET /report`), add optional `decomposition`:
```json
{
  "baseline_kg_co2e": 202.08,
  "optimized_kg_co2e": 25.43,
  "delta_kg_co2e": -176.65,
  "distance_effect_kg": -176.65,
  "fleet_intensity_effect_kg": 0.0,
  "methodology": "GLEC v3.2 ASI / PVM decomposition (modelled)"
}
```

### 4.3 `GET /analytics/timeseries` Bucket Enum
`bucket` accepts `"day" | "hour"` (default `"day"`). When `bucket="hour"`, returns up to 24 hourly buckets (`"08:00"`, `"09:00"`, ...) aggregating routed stop `km` (proportional to route stop share), `litres`, `kg_co2e`, and `orders` by `window_start[:2] + ":00"`.

### 4.4 `POST /ingest/events` (ERP / Webhook Push Sync)
Request body:
```json
{
  "dataset_label": "dn-a-erp-sync",
  "orders": [
    {
      "external_id": "DNA-0001",
      "address": "12 Nguyen Hue, Q1",
      "lat": 10.775,
      "lng": 106.703,
      "receiver": "CoopMart Q1",
      "phone": "0901000001",
      "kg": 45.0,
      "window_start": "08:00",
      "window_end": "10:00",
      "cargo_type": "thuong",
      "notes": ""
    }
  ]
}
```
Response body: same `ImportResult` schema as `POST /orders/import` (`imported`, `errors`, `rows_seen`, `rows_imported`, `skipped_duplicates`, `rows_rejected`, `dedupe: true`, `limits`).

### 4.5 `POST /optimize` Additive Options
`OptimizeIn` accepts optional:
- `cluster_radius_km: float = 3.0`
- `optimizer: Literal["legacy", "ecoalns"] | None = None` (defaults to env `ECOMILES_OPTIMIZER` / `GREENLOGIX_OPTIMIZER` or `"legacy"`)
- `enforce_time_windows: bool = False`
- `enforce_truck_ban: bool = False`
`OptimizeOut` adds optional:
- `optimizer_used: str = "legacy"`
- `restriction_coverage: str = "decision23-2018-v1:unchecked"`
- `ban_conflicts: int = 0`
- `time_window_conflicts: int = 0`
