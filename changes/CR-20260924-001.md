## Verified real contract (live probes 2026-09-24, do NOT re-derive)

- Base URL: `https://places-api.gofa.vn`
- Auth: request header `X-API-Key: <key>` (missing key → `{"error":"missing_api_key"}`)
- AutoComplete: `GET /v5/Place/AutoComplete?input=<text>` → `{"predictions":[{"place_id","description","structured_formatting":{"main_text","secondary_text"},"compound":{...},...}]}`
- Detail: `GET /v5/Place/Detail?place_id=<id>` → `{"result":{"place_id","formatted_address","geometry":{"location":{"lat","lng"}},"compound":{"province","district","commune"},"name",...},"status":"OK"}`
- Quota: `GET /Account/Quota` → `{quota:{limit:15000,used,remaining,endpoints:[{code:"autocomplete",limit:10000,...},{code:"detail",limit:5000,...}]}}` (live counting confirmed: 2 calls consumed by probes)
- Key storage: `apps/api/.env` only (gitignored, confirmed untracked). NEVER commit key, NEVER ship key to browser bundle.
